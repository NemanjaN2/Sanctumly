# Sanctumly cross-platform visual update

This Web source is aligned with the accepted iOS and Android design direction.

- Typography: Geist Sans and Geist Mono, with the actual WOFF2 assets in `public/fonts`.
- Brand palette: Midnight Violet `#130E22`, Sanctum Violet `#8B7CC7`, Coral Reef `#FD6E6E`, Coral Ink `#24101A`.
- Wellness: five weather-inspired mood glyphs (Awful / Bad / Okay / Good / Great) replace yellow face emojis in check-in, chart, average and recent history.
- Attachment: one transparent/violet control with only the plus glyph coral; the menu offers file and image attachments.
- Actions: coral emphasis for primary actions and selected states; violet remains the main surface and orb color.
- Sidebar: Creator and unlimited-message labels are not shown in the personal sidebar; creator permissions and routing remain intact.

The app's data model/API is unchanged.
